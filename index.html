Pipe Labels

Structure "depth" = Rim − Sump (or Rim − lowest invert, if no sump elevation is given) — the closest thing this data has to a manhole's build/barrel height. Labels only draw once you're zoomed in past a certain point (manholes/dots always show) — zoom to a single layer from the 📑 Layers panel first if a corridor-shaped project makes the whole-site view too small to label.

Surface Display

Alternate ways to read a TIN surface, on top of (or instead of) its wireframe — all draw in both 2D plan and 3D orbit, on every visible surface layer.

Very high droplet counts on a large/dense TIN can slow the frame rate — each droplet still falls back to a full-surface search on the rare frame it crosses into a new triangle.

Label Geometry Points

1) Pick the reference alignment — this defines station 0 and direction. 2) Check one or more targets to label: an alignment (its own curves/spirals/profile give real PC/PT/PI/MID/CC/PCC/PRC/TS/SC/CS/ST/SPI/PVC/PVT/PVI/PVCC/PVRC/Hi/Lo/POB/POE/EQN) or a plain line/layer (no curve data, so only its segment MID points can be labeled). Checking several targets at once labels them all together, stationed against the same reference — handy for e.g. labeling a mainline plus every side street off it in one pass. Most types' station is the closest match along the reference (so checking the reference as its own target recovers native stationing); a few — EQN, POT/POC/POS, and every vertical/profile point — always keep the station they're actually defined at, since re-stationing them against an unrelated alignment wouldn't mean anything. CC (circle center) shows no station at all — it's off the physical roadway, at radius distance from the curve.

Points Table

Every currently labeled point, sorted by station — a field stakeout reference sheet. Shows everything computed, including types hidden on-canvas by a category toggle.

Profile View

Station vs. elevation for one alignment. An alignment with an imported <Profile> shows its real design grade line and PVC/PVT/PVI/PVCC/PVRC/Hi/Lo; one without shows its horizontal geometry's own elevation instead, dashed, so it's never mistaken for an actual design profile.

Import a DXF or LandXML (TIN / pipe network) file to begin. Drag to pan, wheel to zoom — on a touchscreen: one finger to pan/orbit, two fingers to pinch-zoom or pan, double-tap to fit.
